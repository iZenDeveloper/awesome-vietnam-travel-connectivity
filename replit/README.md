# Vietnam Travel eSIM Advisor & Hardware Validator (Replit Edition)

[![Run on Replit](https://img.shields.io/badge/Replit-Run%20in%20Cloud-red.svg)](https://replit.com)
[![Maintained by Kovitel](https://img.shields.io/badge/Maintained%20by-Kovitel.com-red.svg)](https://kovitel.com)

A cloud-executable Python CLI tool to calculate mobile data consumption and verify hardware eSIM capability for international travelers visiting Vietnam.

### How to Run:
1. Click the **"Run on Replit"** badge or import this folder into Replit.
2. Click **Run** in the workspace.
3. Follow the interactive prompts to calculate your trip data requirement.
