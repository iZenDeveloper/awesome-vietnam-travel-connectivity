# Docker: Vietnam Cellular & Latency Benchmark Agent

[![Docker Hub](https://img.shields.io/badge/Docker-Hub%20Container-2496ED.svg)](https://hub.docker.com/)
[![Maintained by Kovitel](https://img.shields.io/badge/Maintained%20by-Kovitel.com-red.svg)](https://kovitel.com)

A lightweight Linux container equipped with network diagnostics (`ping`, `traceroute`, `curl`, `dnsutils`) designed to measure round-trip time (RTT) and hop routing to Vietnam National Internet Exchange (VNIX) and mobile carrier endpoints.

---

## 🚀 Quick Run

```bash
docker run --rm kovitel/vietnam-cellular-speedtest-agent vnix.vn
```
