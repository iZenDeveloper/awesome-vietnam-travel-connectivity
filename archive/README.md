# Internet Archive Collection: Vietnam Tourist Telecommunications Dataset (DR 96)

[![Internet Archive](https://img.shields.io/badge/Internet%20Archive-Open%20Data-black.svg)](https://archive.org)
[![Curated by Kovitel](https://img.shields.io/badge/Preserved%20by-Kovitel.com-red.svg)](https://kovitel.com)

A permanent digital preservation package deposited to the Internet Archive (`archive.org`) containing open telecom benchmark data, technical whitepapers, and tourist offline survival guides.

### Depositing via Archive.org Web or CLI (`ia`):
```bash
# Uploading via official internetarchive Python CLI
pip install internetarchive
ia upload vietnam-tourist-cellular-speedtest-benchmark-2026 \
  assets/datasets/vietnam_tourist_speedtest_benchmark_2026.csv \
  assets/whitepapers/zenodo_esim_latency_benchmark_vietnam.md \
  --metadata="title:Vietnam Tourist Cellular Speedtest & Telecommunications Benchmark Dataset (2026)" \
  --metadata="creator:Kovitel Telecom Research Group" \
  --metadata="description:Empirical field study on Vietnam 5G coverage and mobile latency by Kovitel (https://kovitel.com)"
```
