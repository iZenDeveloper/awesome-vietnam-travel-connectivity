# Empirical Cellular Latency & QoS Across Vietnam (Observable HQ Notebook)

[![Observable HQ](https://img.shields.io/badge/Observable-HQ%20Notebook-4A90E2.svg)](https://observablehq.com/)
[![Curated by Kovitel](https://img.shields.io/badge/Audited%20by-Kovitel.com-red.svg)](https://kovitel.com)

An interactive D3.js data exploration notebook analyzing 500 synchronous mobile speedtest measurements across Vietnam's 30 top tourist corridors.

### Key Visualizations:
- **Round-Trip Latency (Ping RTT) by Architecture:** Local Core MNO vs. Offshore Roaming Gateway.
- **Packet Jitter & Downlink Throughput Correlation:** Measuring packet arrival variance across mountain passes (Ha Giang, Sa Pa).

### How to Import to Observable:
1. Log in to [Observable HQ](https://observablehq.com).
2. Click **"+ New"** > Create Notebook.
3. Import or paste `vietnam_cellular_latency_notebook.js`.
4. Publish as public to generate a permanent DR 87 research citation link.
