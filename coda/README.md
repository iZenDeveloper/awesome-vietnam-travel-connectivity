# Vietnam Backpacking, Telecom & Route Cost Calculator (Coda.io Gallery)

An interactive Coda doc template for backpackers and digital nomads traveling in Vietnam. Calculate accommodation, transport, and cellular data costs dynamically.

### How to Duplicate:
1. Open [Coda.io](https://coda.io) and create a new Doc.
2. Import `vietnam_travel_coda_template.md` or copy the Markdown tables.
3. Use Coda's interactive formula controls to plan your budget.
